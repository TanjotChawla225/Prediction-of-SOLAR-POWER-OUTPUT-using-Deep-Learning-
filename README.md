# Prediction-of-SOLAR-POWER-OUTPUT-using-Deep-Learning-
Deep Learning based solar power forecasting (i.e prediction of solar power output) and inverter health monitoring with Streamlit dashboard.
| Folder       | Purpose                    |
| ------------ | -------------------------- |
| `data/`      | CSV datasets               |
| `notebooks/` | EDA + experiments          |
| `src/`       | Data preprocessing scripts |
| `models/`    | Saved DL models            |
| `outputs/`   | Reports & plots            |
| `app.py`     | Streamlit dashboard        |
